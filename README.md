# S-P 表分析工具（S-P Chart Diagnostic Tool）

在瀏覽器中執行的 S-P 表（Student-Problem Chart）分析工具。輸入或上傳二元作答資料（0／1）後，可產生排序後的 S-P 表與 S、P 曲線，計算曲線差異面積、模擬差異比值、學生與試題注意係數，並提供古典測驗理論的試題難度與鑑別度，作為檢視作答組型與試題品質的教學參考。

**作答資料只在使用者自己的瀏覽器中讀取與計算，不會上傳到任何伺服器。**

- 線上版本：https://ang7946.github.io/sp-analysis/
- 開發者：林祖強（國立高雄師範大學 科學教育暨環境教育研究所）／ Tzu-Chiang Lin, Graduate Institute of Science Education and Environmental Education, National Kaohsiung Normal University, Taiwan
- 版本：2026 V10（2026-11-02）

## 功能

1. **資料輸入**：
   - 手動貼上 0／1 作答矩陣：每一列為一位學生、每一欄為一道試題，以空白、逗號或 Tab 分隔；逗號或 Tab 分隔時不允許連續分隔符造成的空欄。
   - 上傳 Excel 檔（.xlsx、.xls），讀取第一個工作表；可自動辨識非數值的文字標籤。
   - 文字輸入與 Excel 皆可指定「第一列為試題題號」「第一欄為學生編號／姓名」；第一列或第一欄為純數字題號、座號時，請手動勾選。
   - 作答區不可有空白漏答、非矩形缺漏或 0／1 以外的數值。
   - 內附文獻範例：Miller 與 Burstein（1981）Table 1（引自 Harnisch & Linn, 1981，18 人 × 5 題）。
2. **S-P 表與曲線**：依學生總分（高至低）與試題答對人數（多至少）排序，同分時依原始輸入順序排列；標示 S 曲線、P 曲線，以及作答與理想組型不一致的格位。
3. **曲線差異面積與模擬差異比值**：
   - 差異面積格數 C = Σ|r_i − h_i|，為 S、P 曲線之間的對稱差格數；完全符合理想 Guttman 組型時 C = 0。
   - 以全體平均答對率 p̄ 為參數，對每一格獨立生成 Bernoulli(p̄) 作答，重複模擬 R 次（500、1000〔預設〕或 2000），估計模擬平均面積 E(C_sim) 與蒙地卡羅標準誤 MCSE = s_C／√R，求得 D*sim = C／E(C_sim)。
   - 使用帶種子的偽亂數產生器（Mulberry32，預設種子 20261028）；相同資料、種子與模擬次數會得到相同結果。
4. **注意係數**：可切換 Sato 原始注意係數（CS／CP）或 Harnisch–Linn 修正注意係數（CS*／CP*，值域 0–1）。全對、全錯或分母為零時標示為無法計算（null），不以 0 代替。
5. **學生作答組型**：依得分率（> 75%、50%–75%、< 50%）與注意係數是否達提醒門檻，分為六類組型描述與教學待查假設；無法計算者另列一類。
6. **古典測驗理論**：試題難度 P（答對比例）與鑑別度 D（高、低分組各取 27%，g = max(1, floor(0.27 × N))）。切點同分時，以邊界同分學生的期望值加權計算，結果不受同分學生的排列順序影響。

分析結果顯示於網頁上的表格。

- **線上使用**：開啟 GitHub Pages 網址即可。
- **下載使用**：下載 `index.html` 後以瀏覽器開啟。讀取 Excel 需要從 cdnjs 載入 SheetJS，字型由 Google Fonts 載入，因此仍需網路連線；手動貼上作答矩陣的分析不依賴這兩項服務。

## 方法學注意事項

- **D*sim 的性質**：D*sim 是描述性的標準化比值，不是統計顯著性檢定（沒有 p 值），也不是 KR-20、Cronbach's α 等信度或內部一致性係數；在特定交錯組型下數值可能大於 1。MCSE 只反映有限次模擬的數值估計誤差，不是 95% 信賴區間，也不代表受試者抽樣的不確定性。
- **D*sim 的分界**：畫面上的 0.35／0.60 分界僅借鏡傳統 D* 文獻慣例，屬工具暫定的觀察提示；目前尚未建立此模擬分母與傳統佐藤（1975）D* 基準（或 D_B(M) 查表近似式）的理論等價性。正式研究宜報告面積 C、模擬模型參數（p̄、種子、R）與精度（MCSE）。
- **注意係數門檻**：原始係數採傳統教學測驗慣例（0.5 留意檢視、0.75 偏離明顯）；修正係數採文獻常見的 0.3 為提醒門檻，並以 0.5 作為本工具自訂的高偏離提示。這些界值皆為實務篩檢的經驗提示，不是統計臨界值。CP* 與 CP 的比值隨各題答對人數與學生總分分布而改變，兩者之間沒有固定的換算關係。
- **解讀界限**：低注意係數只代表作答符合本樣本的難易排序，不能單獨保證高鑑別度或高測驗資訊量。學生注意係數反映本次作答偏離樣本難易排序的程度，不是心理注意力的測量；高係數可能涉及題意誤讀、單元熟悉度差異、試題多向度、粗心或猜測等多種待查假設，不應直接視為心理特質的定論。
- **難度與鑑別度的分類**：難度依答對比例以 0.8、0.6、0.4、0.2 為界，分為很容易、容易、中等、困難、很困難；鑑別度以 0.4、0.3、0.2、0.1 為界，分為很好、好、可接受、需改進、很差。樣本少於 2 人或全體總分相同時，鑑別度標示為無法計算。

## 文獻範例比對

以 Miller 與 Burstein（1981）Table 1 的 18 × 5 作答矩陣重算，18 位學生的 CS，以及第 1、3、4、5 題的 CP，皆與原表所印兩位小數一致。第 2 題（c₂ = 10）依公式重算為 (28 − 26)／(28 − 10 × 38／18) = 9／31 ≈ 0.290，原表印為 .28，差異無法以四捨五入解釋；本工具維持依公式計算，並在畫面中註記此差異。
