請以面積 C 與各別 CS/CP 進行診斷
1. S-P 曲線差異面積格數 (C)：指排序後矩陣中，S 曲線（學生總分累積線）與 P 曲線（試題答對人數累積線）之間所夾的對稱差面積格數：C = Σ_i |r_i - h_i|。
• C 恆為非負偶整數。當作答完全符合理想 Guttman 階層組型時，S 曲線與 P 曲線完全重疊，此時 C = 0。
• C 越大，代表學生總分分佈與試題難度分佈之間的落差越大（曲線分離程度越高）。
2. 為什麼暫不顯示差異係數 D*？
• 文獻中的 D* = C / [4 × N × J × p̄ × (1 - p̄) × D_B(M)] 需依賴佐藤（1975）的二項分佈邊界查表常數 D_B(M)。在未載入經完整核對之原著常數表前，任意以公式代換會導致分母失真，故本工具直接提供精確無誤差之幾何面積格數 C 與面積佔比 C / (N × J)。

試題注意係數與品質評估 (Sato 原始 CP)

以下依S-P 表排序後之試題順序（由易至難）排列，並保留原始題號方便對照：

S-P 排序 原始題號 答對人數 / 百分比 Sato 原始 CP 修正係數 CP* (參考) 試題品質評估與可能原因參考
1. 兩個公式版本的差異：
• Sato 原始試題注意係數 (CP)：比較「實際答對學生的總分加權和」與「最高分前 c_j 位學生的總分和」，分母以全體平均總分 r̄ 為基準。數值 ≥ 0，當高分群答錯而低分群答對的情形顯著時，數值可能大於 1。
• Harnisch–Linn 修正注意係數 (CP*)：分母改為「最高分前 c_j 位學生總分和」減去「最低分後 c_j 位學生總分和」，將值域嚴格標準化於 0 ~ 1 之間（0 為完美契合，1 為完全顛倒）。
2. 判讀門檻慣例與注意事項：
• 在佐藤傳統慣例中，原始 CP < 0.5 視為一致性尚可，0.5 ≤ CP < 0.75 建議留意檢視，CP ≥ 0.75 表示偏離明顯。若切換至修正係數 CP*，因其分母較大、數值較小，傳統常以 0.3（約對應原始 0.5）與 0.5 作為參考觀察點。
• 當全體學生皆答對、皆答錯，或所有學生總分完全相同時，分母為零，數學上無定義，系統將標示為 無法計算 (null)，不以 0 代替。

學生注意係數與學習診斷 (Sato 原始 CS)

以下依S-P 表排序後之學生順序（總分由高至低）排列，並保留原始學生編號：

S-P 排序 原始學生編號 得分 / 百分比 Sato 原始 CS 修正係數 CS* (參考) 作答組型診斷與教學輔導參考
1. 注意係數的本質：反映該生作答組型偏離「本次樣本試題難易排序」的程度。它不是心理注意力測驗，數值偏高代表該生「答錯較多人會的簡單題，卻答對較少人會的難題」。
2. 雙軌診斷分類參考（結合白話輔導方向與客觀組型描述）：
🟢 得分率 > 75% 且係數正常：作答組型與整體難易排序一致（表現穩定良好）。
🟡 得分率 > 75% 但係數偏高：作答組型與難易排序較不一致（高分但錯簡單題，可能偶有粗心失誤、題意誤讀或特定基礎概念遺漏，建議檢視錯題歷程）。
🔵 得分率 50%–75% 且係數正常：作答組型穩定（基礎題大致掌握，可循序加強進階題型）。
🟠 得分率 50%–75% 但係數偏高：作答組型偏離預期（可能準備尚欠全面、部分概念混淆或偶有粗心與猜測，建議個別釐清迷思概念）。
🟣 得分率 < 50% 且係數正常：作答組型符合難易階層，惟整體得分偏低（基礎學力可能尚待充實，建議由淺入深進行補救教學）。
🔴 得分率 < 50% 且係數偏高：作答組型極不一致且得分偏低（可能學習基礎較不穩定、受試題多向度影響或有隨機猜測傾向，建議深入了解解題歷程與學習困難）。
⚪ 無法計算（滿分、零分或分母為零）：全對或全錯之作答向量缺乏組型變異（分母為 0），依統計規範不計算注意係數，僅依總分呈現表現。
