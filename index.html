1. S-P 曲線差異面積格數 (C)：指排序後矩陣中，S 曲線（學生總分累積線）與 P 曲線（試題答對人數累積線）之間所夾的對稱差面積格數：C = Σ_i |r_i - h_i|（恆為非負偶整數；完全符合理想 Guttman 階層組型時 C = 0）。
2. 獨立 Bernoulli(p̄) 模型的蒙地卡羅隨機基準 (D*sim)：
• 模型定義：以觀測矩陣之全體平均答對率 p̄ = T / (N × J) 為參數，對每個「學生 × 試題」儲存格獨立生成 Bernoulli(p̄) 二元作答（非固定邊際之置換檢定），重複模擬 R 次並每次重新排序求得曲線面積，計算模擬平均面積 E(C_sim) 與蒙地卡羅標準誤 MCSE = s_C / √R。
• 比值性質與 MCSE 意義：D*sim = C_實際 / E(C_sim)，屬描述性標準化比值而非統計顯著性檢定（無 p 值），亦非 KR-20 或 Cronbach's α 等信度／內部一致性係數，且在特定交錯組型下數值可能大於 1。MCSE 僅衡量有限次蒙地卡羅模擬之數值估計誤差，並非 95% 信賴區間，亦非受試者抽樣不確定性。
• 可重現性與方法學界限：系統採用帶種子之確定性偽亂數產生器（Mulberry32），相同資料、種子（Seed）與模擬次數（R）必得相同結果。畫面所示 0.35 / 0.60 分界僅為借鏡傳統 D* 文獻慣例之工具暫定觀察提示；目前尚未建立此模擬分母與傳統佐藤（1975）D* 基準（或 D_B(M) 查表近似式）之理論等價性，正式研究宜先報告面積 C、模擬模型參數與精度。

S-P 排序 原始題號 答對人數 / 百分比 Sato 原始 CP 修正係數 CP* (參考) 試題組型評估與可能原因假設
1. 兩個公式版本的定義：
• Sato 原始試題注意係數 (CP)：比較「實際答對學生的總分加權和」與「最高分前 c_j 位學生的總分和」，分母以全體平均總分 r̄ 為基準。數值 ≥ 0，且可能大於 1。
• Harnisch–Linn 修正注意係數 (CP*)：分母改為「最高分前 c_j 位學生總分和」減去「最低分後 c_j 位學生總分和」，將值域標準化於 0 ~ 1 之間。
2. 門檻來源與非固定換算說明：
• 兩者比值 CP* / CP = (best - c_j × r̄) / (best - worst) 會隨各題答對人數與學生總分分佈而改變，數學上不存在固定常數換算關係。
• 原始係數採傳統教學測驗慣例（0.5 留意檢視、0.75 偏離明顯）；修正係數採文獻常見之 0.3 作為提醒門檻（例如 McArthur & Hafner, 1982, ERIC ED224841），並以 0.5 作為本工具之高偏離自訂提示（1975／1981 原著完整頁碼仍待直接核對）。上述界值皆為實務篩檢之經驗提示，並非固定型一錯誤率之統計顯著性臨界值；且低 CP 僅反映作答符合總分排序，不能單獨保證高鑑別度或高測驗資訊量。
3. 內建 18×5 文獻示例出處與第 2 題數值差異註記：
• 內建 18 人 × 5 題示例取自 Miller & Burstein (1981), Evaluation Design Project: Multilevel Interpretation of Evaluation Data Study (ERIC ED212649, PDF 第 66 頁／印刷頁 32, Table 1；該表註明引自 Harnisch & Linn, 1981)。
• 依該表 90 格作答矩陣與本工具已驗證之 Sato 原始公式重算，18 位學生之 CS 與第 1、3、4、5 題之 CP 均與印表兩位小數吻合；惟第 2 題（c_2 = 10）按公式重算為 (28 - 26) / (28 - 10 × 38 / 18) = 9 / 31 ≈ 0.290323，而原報告 Table 1 印為 .28。此差異無法以四捨五入解釋，特此記錄文獻印表值與矩陣重算值之差異，本工具維持正確公式不予修改迎合。

S-P 排序 原始學生編號 得分 / 百分比 Sato 原始 CS 修正係數 CS* (參考) 單次作答組型描述與教學待查假設
1. 注意係數的本質與解釋界限：反映該生本次作答組型偏離「本樣本試題難易排序」的程度。低係數僅代表單次作答符合樣本難易階層，不直接證明跨時間之心理穩定性；高係數代表「答錯較多人會的題目、卻答對較少人會的題目」，可能涉及題意誤讀、單元熟悉度差異、試題多向度、粗心或猜測等多種待查假設，不應直接視為心理特質定論。
2. 組型分類提示參考：
🟢 得分率 > 75% 且係數低於門檻：本次作答組型與樣本難易排序吻合，且高分題掌握度佳。
🟡 得分率 > 75% 但係數達提醒門檻：總分高但作答組型偏離樣本難易排序（答錯部分較易題，可能源於粗心失誤、題意誤讀或特定基礎概念疏漏，建議結合錯題歷程查核）。
🔵 得分率 50%–75% 且係數低於門檻：本次作答組型符合樣本難易階層（較易題大致掌握，可循序加強進階題型）。
🟠 得分率 50%–75% 但係數達提醒門檻：作答組型與樣本難易排序較不一致（可能特定單元準備尚欠全面、概念混淆或偶有粗心與猜測，建議個別釐清迷思概念）。
🟣 得分率 < 50% 且係數低於門檻：作答組型符合樣本難易階層惟整體得分偏低（基礎學力可能尚待充實，建議由淺入深進行補救教學）。
🔴 得分率 < 50% 且係數達提醒門檻：得分偏低且作答組型明顯偏離樣本難易排序（可能學習基礎較不平均、受試題多向度影響或有隨機猜測傾向，建議深入了解解題歷程）。
⚪ 無法計算（滿分、零分或分母為零）：全對、全錯或試題難度無變異時分母為 0，依統計規範回傳 null，僅依總分呈現表現。
